**Day 10 Deliverable | ABTalks 60-Day Claude AI Challenge — 10-Day Capstone**

Copy the prompt below into a new Claude conversation each day of your 30-Day Growth Plan. Only change the DAY NUMBER and TODAY'S MILESTONE fields each time — everything else stays the same throughout the month.

## The Reusable Prompt

```
Today is Day [DAY NUMBER] of my 30-Day Growth Plan for GD Prep Coach, a full-stack
AI-powered Group Discussion practice platform I built as a 10-day capstone for the
ABTalks 60-Day Claude AI Challenge.

Project context:
- Tech stack: React (Vite), Node.js/Express, MongoDB Atlas, JWT auth, Google Gemini
  API for AI analysis, deployed on Vercel (frontend) + Render (backend)
- GitHub repo: https://github.com/ramyanagesh29/gd-prep-coach
- Live app: https://gd-prep-coach.vercel.app
- Reference docs are in the /docs folder of the repo: ARCHITECTURE.md, SCHEMA.md,
  API.md, PROJECT-STRUCTURE.md, and my 30-day-growth-plan.md

Today's milestone (from my 30-day-growth-plan.md):
[TODAY'S MILESTONE — paste the exact row from the growth plan table here]

Standing rules:
- Review the existing codebase structure before writing code — ask me to paste
  relevant existing files if you need to see them first.
- Build only today's milestone. Do not redesign existing features or jump ahead
  to future days in the growth plan.
- I have working full-stack development experience at this point (completed the
  original 10-day capstone), so you can move a bit faster than a beginner-level
  walkthrough — but still explain any new concept, library, or pattern I haven't
  used in this project yet.
- Use only free tools/services unless I explicitly say otherwise.
- Generate complete, copy-pasteable files — no snippets or "add this below" instructions.
- Tell me exactly which files are new vs. modified, and where each belongs.
- Give me exact terminal commands for anything I need to run.
- After implementation, tell me how to verify today's milestone works correctly.
- At the end, give me a one-line commit message suggestion for today's work.

Let's start.
```

---

## Notes on Using This Prompt

- Keep the milestone text exact. Copy it directly from 30-day-growth-plan.md rather than paraphrasing — this keeps each day scoped correctly and prevents accidental scope creep into future days' work.
- Start a fresh conversation each day. Unlike the original 10-day capstone, this 30-day plan is designed for fresh daily conversations, since each milestone is self-contained and the prompt already includes all necessary project context.
- Update the experience-level line if needed. If you take a long break between days, feel free to ask for a slower, more explanatory pace again.
